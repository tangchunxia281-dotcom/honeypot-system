# 蜜迹：证据驱动的智能蜜罐分析系统

传智小分队 · 比赛交付版 2.4 · 2026年10月30日

代码仓库：https://github.com/tangchunxia281-dotcom/honeypot-system

蜜迹通过六类受控诱饵服务采集可疑行为，将原始事件、规则判断、模型意见、会话关联和人工复核组织为可追溯的调查过程。系统沿用五个工作入口，支持本机运行及可选的云端大模型接入。

## 项目功能

| 工作入口 | 主要功能 |
| --- | --- |
| 安全概览 | 六协议记录统计、最近事件、调查进度、攻击地图大屏 |
| 攻击事件 | 协议与来源筛选、证据原文、规则与模型意见、人工复核、风险目标档案 |
| 会话分析 | 采集时间线、程序关联图、虚拟交互回放 |
| 证据调查 | 建案快照、限定范围补查、带引用故事线、反馈、状态管理与JSON导出 |
| 系统与评测 | 本机模型配置及下载、云端模型、采集服务、分类模型、效果评测与调用记录 |

支持Web、SSH、MySQL、Redis、FTP和Telnet。协议服务使用虚拟数据与受控响应；规则、分类建议、大模型分析和人工意见分别留存。模型可选，基础采集和规则检测独立运行。

## 系统架构

Python 3.11+ / Flask / SQLite / 原生JavaScript / Canvas地图。

`main.py`统一管理诱饵与管理端；`db/`保存事件；`investigation_core/`负责本机证据索引和调查；`utils/classifier.py`通过限额异步队列接入分类服务；`utils/local_ai.py`对接Ollama或HTTPS云端服务。前端保持五入口与统一深色设计。

## 安装与运行

1. 安装Python 3.11或更高版本并加入PATH。交付验收环境为Windows、Python 3.12。
2. 解压到独立目录，双击“安装环境.cmd”，按requirements-lock.txt安装依赖到.venv-local。
3. 双击“启动比赛版.cmd”，首次设置至少12位管理员密码。
4. 打开 http://127.0.0.1:5001/super/login ，账号admin，使用刚设置的密码登录。
5. 默认端口：Web 5000、SSH 2222、MySQL 13306、Redis 16379、FTP 2121、Telnet 2223。管理端5001，默认均仅本机监听。
6. 启动窗口按Ctrl+C停止服务。修改协议或大模型配置后，重启全部服务使其生效。

Linux命令：`python3 -m venv .venv-local`，安装锁定依赖后执行`.venv-local/bin/python scripts/competition.py start`。

## AI部署方式

- **本机模型**：安装并启动Ollama，进入“系统与评测 / 模型配置”，选择或下载模型，执行真实调用验收，再保存并启用。
- **云端模型**：进入“云端模型”，填写HTTPS地址、模型名及个人API密钥，确认数据发送与计费选项后保存并重启；使用“验收当前运行模型”检查真实连接。
- **分类模型**：部署AI组提供的分类服务与权重；进入“分类模型”，配置本机`/api/v1/detect`地址并启用。协议详见`docs/分类模型字段对接.md`。

配置模板：honeypot.ini.example、ai.local.ini.example、classifier.ini.example、.env.example。环境变量优先于对应配置；程序不会自动加载.env。真实配置、密钥、运行库和模型权重不提交仓库。
