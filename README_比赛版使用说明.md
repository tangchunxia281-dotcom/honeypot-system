# 蜜迹2.4使用说明

## 首次使用

按README安装Python与锁定依赖，运行启动比赛版.cmd，设置管理员密码并登录。后台与Web诱饵是两个不同入口；管理端为5001，Web诱饵为5000。

## 一条完整操作链

1. 在自己的本机诱饵产生测试请求，进入攻击事件，索引新记录。
2. 调整协议、来源、关键词和时间范围，选择记录查看原文；规则、分类、大模型与人工意见独立展示。
3. 查看所属会话，按需要调整范围；采集时间线、程序关联图、交互回放在本页切换。
4. 按当前范围建立调查，保存建案快照；在提问与补查中提出具体问题，核对引用与故事线。
5. 保存人工反馈和处理状态，导出调查JSON。

## 风险目标

攻击事件的“风险目标”是来源复核档案。可按IP、标签或备注搜索，新增和编辑风险等级、状态与笔记；“从当前证据提取候选”只扫描当前范围最近100条已索引记录，由使用者确认保存。

“查看来源事件/会话”进入该IP记录，再沿现有流程建立调查。风险目标状态用于人工管理，不操作系统防火墙。

## 服务与模型

- 采集服务：管理四类扩展协议的开关和端口；保存后重启。端口检测与协议交互验收分别进行。
- 分类模型：本机服务地址，单次超时0.1至5秒，异步队列32项；连续故障冷却30秒。结果不覆盖规则分，正常分类的有效加分为0。
- 云端模型：HTTPS地址、模型名、密钥保存在本机配置中，界面不回显密钥。启用前确认脱敏证据发送与费用选项，保存后重启。切回本机模式在模型配置保存并启用。
- 本机模型：保留原2.3候选下载、模型选择和真实调用验收。

## 受控协议默认端口

| 协议 | 端口 | 演示内容 |
| --- | --- | --- |
| Web | 5000 | 页面、探测输入、虚拟预览与ERP |
| SSH | 2222 | 虚拟终端与登录审计 |
| MySQL | 13306 | 握手、诱饵认证和虚拟查询 |
| Redis | 16379 | RESP命令与诱饵键值 |
| FTP | 2121 | 被动模式、虚拟目录和文件 |
| Telnet | 2223 | 虚拟设备登录与命令 |

MySQL不向客户端索取本地文件；FTP使用PASV/EPSV，不发起主动数据连接。输入长度、连接并发及会话时长由服务端限制。

## 备份与重启

停止服务后备份database目录及本机配置。更换电脑时安装环境并设置新密码；发布源代码时仅提交模板，不带运行配置、私钥、数据库、日志或虚拟环境。
