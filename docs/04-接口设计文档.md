## 1. 通用约定

### 1.1 Dashboard 统一响应包装

除页面渲染与附件导出外，Dashboard 所有 `/api/*` 接口返回 JSON：

```json
{ "code": 0, "message": "ok", "data": { } }
```

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 1 | 业务失败（message 说明原因） |

HTTP 状态码语义照常使用：400 参数非法、401 未登录、403 CSRF/权限、404 不存在、409 冲突、429 限速。

### 1.2 Dashboard 鉴权机制

| 机制 | 说明 |
| ---- | ---- |
| 登录 | `POST /super/login` 成功后写入 Session（Cookie `DASHSESSID`，HttpOnly，SameSite=Lax，默认 1440 分钟） |
| 会话校验 | 全部 `/api/*` 经 `enhanced_login_required`，未登录 → 401 或 302 跳登录 |
| CSRF | 写操作（POST）须带请求头 `X-CSRF-Token`（token 在 `/dashboard` 页面 `<meta name="csrf-token">` 下发），同时校验 Referer/Origin 同源 |
| 限速 | 登录接口 60s 窗口 8 次失败封禁 300s |

默认管理账号（仅实验环境，生产必须修改）：`admin / Admin@2024!`。

### 1.3 参数通用钳制

- `limit`：1–500，默认 100；`offset`：0–50000；`hours`：1–720（24h/7d/30d 三档归一）。
- 标识符 `identifier`：24 位小写十六进制（`[a-f0-9]{24}`），不符 → 400。

## 3. Dashboard 态势数据 API

### 3.1 GET /api/get_event_logs — 事件日志查询

| 参数 | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| limit | int | 100 | ≤500 |
| offset | int | 0 | ≤50000 |
| source | string | '' | web/ssh/mysql/redis/ftp/telnet/dashboard/system |
| severity | string | '' | low/medium/high/critical |
| event_type | string | '' | 事件类型 |
| keyword | string | '' | payload/tags/ip 模糊 |
| hours | int | 24 | 时间窗 |

响应 `data`：`{logs:[{id,timestamp,source,severity,event_type,src_ip,session_id,tags,payload,raw_ref,extra}...], total}`。

### 3.2 GET /api/get_event_stats — 事件统计

参数：`hours`。响应 `data`：总量、分级分布、来源分布、类型 Top、时间曲线（3s 缓存）。

### 3.3 GET /api/get_geo_data — 攻击地理分布

参数：`hours`。响应 `data`：`[{ip,country,province,city,latitude,longitude,count,severity_max}...]`（按窗口档位限量 60/100/140）。

### 3.4 GET /api/realtime — 实时事件流

参数：`after_id`（增量游标，可选）。响应 `data`：`{events:[...], latest_id}`。前端按周期轮询。

### 3.5 GET /api/server_info · GET /api/system_status

- `/api/server_info`：主机名、OS、内核、Python、运行时长、各服务端口监听状态。
- `/api/system_status`：CPU/内存/磁盘/网络实时指标（psutil，采集失败字段降级为 null）。

### 3.6 GET /api/suspicious_requests — 可疑请求列表

参数：`limit/hours`。响应 `data`：`[{id,src_ip,session_id,method,path,threat_score,is_suspicious,create_time,reasons}...]`（基于行为分析，非规则匹配；窗口档限量 50/80/120）。

### 3.7 GET /api/session_analysis — 会话攻击链

参数：`limit/hours/min_count`。响应 `data`：`[{session_id,src_ip,request_count,path_sequence,threat_level,first_seen,last_seen}...]`。

### 3.8 GET /api/login_audit — 登录审计

响应 `data`：`[{time,ip,result,user_agent}...]`（近 30 条）。

## 4. Dashboard 风险目标标注 API

全部写接口需 `X-CSRF-Token` + 同源 Referer。

### 4.1 GET /api/risk_targets — 列表

| 参数 | 说明 |
| ---- | ---- |
| target_type | 默认 ip |
| risk_level | low/medium/high/critical |
| status | watching/banned/handled |
| keyword | 值/备注/标签模糊 |
| limit/offset | ≤500 / ≤50000 |

响应 `data`：`{targets:[{id,target_type,target_value,risk_level,status,tags,note,source,first_seen,last_seen,event_count,created_at,updated_at}...]}`（按 event_count、updated_at 倒序）。

### 4.2 POST /api/risk_targets/derive — 触发自动识别

请求体：`{"hours": 24}`（可选，1–720）。
响应：`{"code":0,"data":{"derived": <upsert 数量>}}`。
规则：近 N 小时六类蜜罐来源事件按 src_ip 聚合，≥2 事件且最高严重度 ≥medium 方入库；**manual 记录仅刷统计不覆盖标注**。

### 4.3 POST /api/risk_targets — 新建/更新（按 target_value 幂等）

```json
{"target_value":"1.2.3.4","target_type":"ip","risk_level":"high","status":"watching","tags":["scanner"],"note":"备注"}
```

校验：target_value 必填（≤64）；非法 level/status 归一化；tags ≤20 项；note ≤2000。
响应：`{"code":0,"data":{"ok":true,"id":1}}`；失败 `{"code":1,"message":"target_value 不能为空"}`。

### 4.4 POST /api/risk_targets/{id} — 按 ID 更新

请求体为可更新字段子集（target_type/target_value/risk_level/status/tags/note/source）。无可更新字段 → `{"code":1,"message":"无可更新字段"}`。

### 4.5 POST /api/risk_targets/{id}/delete — 删除

响应：`{"code":0,"data":{"ok":true}}`。

## 7. 远程 AI 检测服务契约（:8003，默认关闭）

客户端：`utils/ai_client.py`（`AI_XSS_ENABLED=1` 或 honeypot.ini `[ai] enabled=true` 启用）。超时默认 1s（0.1–10），连续失败 3 次熔断退避 30s。

### 7.1 POST /api/v1/detect — 请求级攻击推断（v2 契约）

请求 JSON：

```json
{
  "path": "/search",
  "query": "q=<script>alert(1)</script>",
  "body": "",
  "method": "GET",
  "user_agent": "...",
  "source": "web",
  "ip": "1.2.3.4",
  "session_id": "web-abc123...",
  "extra": {}
}
```

字段文本先经客户端脱敏与限长（默认 ≤5000 字符）。

响应 JSON：

```json
{
  "attack_type": "xss",
  "is_attack": true,
  "attack_prob": 0.97,
  "ai_points": 18,
  "confidence": 0.93,
  "high_risk": true,
  "reasons": ["..."],
  "signals": {"...": "..."},
  "model_label": "xss-bert-v2"
}
```

| 字段 | 说明 |
| ---- | ---- |
| ai_points | 0–25 加权分，由蜜罐累加进规则威胁分（核心契约） |
| is_attack / high_risk | 布尔判定 |
| attack_prob / confidence | 0–1 概率 |

客户端校验：字段缺失、类型非法、ai_points 越界 → 计 invalid_responses 并按失败处理（熔断计数），不影响主流程。

### 7.2 GET /model/info — 模型信息

响应：`{"model_label":"...","version":"...","features":[...]}`（客户端缓存 TTL 300s）。

## 8. AI 推理网关接口（:11500，默认关闭）

鉴权：每客户端 Bearer Token——请求头 `Authorization: Bearer <token>`，网关以 SHA-256(token) 与配置 `token_hash` 做 hmac 比对。全部接口 JSON，`{code:0,data:...}` / `{code:1,reason:...}`。

### 8.1 POST /v1/jobs — 提交推理任务（202）

```json
{
  "request_id": "24hex幂等键",
  "task": "probe|ssh_reply|web_reply|log_chat|general_chat|active_plan|active_story|web_detect|log_report",
  "messages": [{"role":"system|user|assistant","content":"..."}],
  "schema": {"...": "可选 JSON schema(≤6KB, 禁$ref)"},
  "options": {"timeout":20, "num_predict":512, "num_ctx":4096, "think":false}
}
```

校验：request_id 24hex；messages 1–12 条；options 白名单且范围 timeout 5–30 / num_predict 64–1024 / num_ctx 512–8192；payload ≤24KB；task 须在客户端授权列表。
幂等：同 (client, request_id) 重复提交返回原任务。
错误：`401 未认证`、`400 payload_invalid/task_invalid/messages_invalid/schema_invalid/options_invalid/input_too_large`、`403 task_forbidden`、`429 gateway_queue_full / gateway_client_pending / gateway_client_budget`。
响应：`{"code":0,"data":{"id":"24hex","status":"queued"}}`。

### 8.2 GET /v1/jobs/{identifier} — 查询结果

响应 `data`：`{id,status,result,reason,created,started,finished}`；status ∈ queued/running/completed/fallback/cancelled。他人任务 → 404。

### 8.3 POST /v1/jobs/{identifier}/cancel — 取消

成功 `{"code":0,"data":{"cancelled":true}}`；不存在 `404 {"code":1,"reason":"not_found"}`。

### 8.4 GET /v1/status — 网关状态

响应 `data`：队列深度、运行中数、熔断剩余秒、各客户端配额用量、模型端健康。

## 9. 团队数据中心接口（:5169，默认关闭）

两类鉴权：
- **成员浏览器**：`POST /login` 成功后 Session（Cookie `honeypot_center`，SameSite=Strict，30 分钟）；非 GET 请求须带 `X-CSRF-Token`（`GET /api/session` 下发 csrf）；角色 admin/analyst/viewer。
- **传感器节点**：`Authorization: Bearer <token>`（散列比对）。

通用约束：请求体 ≤256KB，JSON 必须为对象；错误统一 `{error:...}` + 状态码（400/401/403/404/409/413/429/503）。

## 11. 错误码汇总

| 场景 | HTTP | 负载 |
| ---- | ---- | ---- |
| 未登录/会话失效 | 401 | `{"code":1,"message":"unauthorized"}` 或 `{"error":"login_required"}` |
| CSRF 缺失/错误 | 403 | `{"code":1,"message":"forbidden"}` / `{"error":"csrf_invalid"}` |
| 角色不足 | 403 | `{"error":"role_denied"}` / `{"error":"scope_denied"}` |
| 参数非法 | 400 | `{"code":1,"message":"编号无效"}` / `{"error":"..."}` |
| 资源不存在 | 404 | `{"code":1,"msg":"..."}` / `{"error":"not_found"}` |
| 并发修订冲突 | 409 | `{"error":"revision_conflict"}` |
| 限速 | 429 | `{"error":"login_rate_limit"}` / gateway Overflow 系列 |
| 请求过大 | 413 | `{"error":"request_too_large"}` |
| 存储不可用 | 503 | `{"error":"storage_unavailable"}` |

## 12. 鉴权方式对照总表

| 接口面 | 方式 | 凭证 |
| ---- | ---- | ---- |
| Dashboard /api/* | Session + CSRF + 同源 Referer | DASHSESSID Cookie + X-CSRF-Token |
| Web 蜜罐 :5000 | 无（诱捕） | — |
| 远程 AI :8003 | 部署侧网络隔离（回环） | 无应用层鉴权 |
| AI 网关 /v1/* | Bearer Token（SHA-256 散列比对） | Authorization 头 |
| 团队中心（成员） | Session + CSRF + 角色 | honeypot_center Cookie + X-CSRF-Token |
| 团队中心（传感器） | Bearer Token | Authorization 头 |
