## 1. 通用大模型推理接入

### 1.1 配置文件

根目录新增 `ai.local.ini`（已加入 `.gitignore`，不会提交）：

```ini
[ai]
enabled = true
ssh_enabled = true
web_interaction_enabled = true
provider = deepseek
api_key =                  # ← 待填：sk- 开头
deepseek_base_url = https://api.deepseek.com
deepseek_model = deepseek-chat
analysis_enabled = true
detection_enabled = true
```

支持三种 provider，互斥启用：

| provider | 必填项 | 说明 |
| --- | --- | --- |
| `deepseek` | `api_key` | DeepSeek 官方 API（OpenAI 兼容） |
| `local` | `base_url` + `model` | 本机 Ollama |
| `gateway` | `gateway_url` + `client_token` | 共享推理网关 `ai_gateway` |

环境变量 `HONEYPOT_AI_API_KEY` 可覆盖文件中的 Key，避免把密钥落盘。

### 1.3 验收

```powershell
uv run python scripts/ai_selftest.py     # 无需 Key：验证接线与协议（本地伪端点）
uv run python scripts/ai_verify.py       # 需要 Key：连通性 + 一次真实调用
uv run python scripts/ai_verify.py --full  # 需要 Key：再加 报告/问答/研判/交互 全链路
```

- `ai_verify.py` 退出码：0 通过 / 1 调用失败 / 2 未配置
- `--full` 使用独立临时库，不污染现有 AI 运行数据（报告、研判、交互记录均隔离）
- 未填 Key 时 `ai_verify.py` 以退出码 2 明确提示，不会发起任何网络调用

### 2.1 行为说明（安全边界）

- **模型不生成自由文本命令**：SSH 只能从 `not_found / unavailable / permission_denied / profile_summary` 中选；Web 只能从 `preview_pending / format_error / service_busy` 中选。正文由程序模板渲染。
- **不访问目标地址**：`/api/preview` 只做字符串校验与任务模拟，不会请求 `url`。
- **Cookie 隔离**：预览任务与 ERP 登录态都绑定随机 `*_sid` cookie；换一个浏览器读取同一 job 返回 404。
- **规则优先**：AI 检测只做补充入队，不修改 `threat_score`；AI 关闭/未配置时全部降级为 `program`/`fallback` 且请求正常响应。
- **限流例外**：`/api/preview`、`/api/erp/*` 不返回扫描器级 429（它们有自己的每 IP 交互配额），避免虚拟业务被高频探测打断。

## 4. 接入状态与运维提示

DeepSeek Key 已写入 `ai.local.ini`（该文件已加入 `.gitignore`），真实调用与全链路验收均已通过，
AI 工作区 7 个页面、SSH/Web 受控交互、周期报告与调查追问全部可用。

运行期注意：

- **成本控制**：`detection_enabled = true` 会对 Web 请求做异步复核，默认 `normal_sample_every = 20`
  （正常流量 1/20 采样）、`detection_per_ip_hour = 20`。若只想保留规则分，把 `detection_enabled` 设为 `false`。
- **交互闭环**：`ssh_enabled` / `web_interaction_enabled` 控制模型是否参与策略选择；关闭后仍返回确定性人设内容。
- **健康检查**：账号 `/v1/models` 只列 `deepseek-flash`、`deepseek-v4-pro` 时，`deepseek-chat` 会显示
  `ready_for_call_alias`，这是正常的服务端别名行为，不代表配置错误。
- **重新验收**：`uv run python scripts/ai_verify.py --full`（约 6 次真实调用，使用独立临时库，不影响现有数据）。
- **换 Key / 换模型**：改 `ai.local.ini` 或设置 `HONEYPOT_AI_API_KEY`、`HONEYPOT_AI_MODEL` 后重启主控进程。
