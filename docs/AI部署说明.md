# AI部署说明

## 本机模式

安装并启动Ollama。进入“系统与评测 / 模型配置”，先检测环境，选择已安装模型或下载候选模型，发起真实调用验收，然后保存启用并重启全部服务。模型下载大小、内存和显存需求由模型版本决定；候选清单用于选择，不代表所有候选具有相同效果。

`ai.local.ini`中的`context_length`控制上下文（512至8192），`gpu_layers=-1`使用Ollama自动调度，0表示CPU，正整数表示部分GPU卸载。按设备资源调整；基础规则与采集可独立运行。环境变量`HONEYPOT_AI_CONTEXT_LENGTH`和`HONEYPOT_AI_GPU_LAYERS`可覆盖这两项。环境变量不会自动从.env读取。

## 云端模式

在“云端模型”填写HTTPS服务地址、模型名、API密钥，阅读并勾选发送脱敏证据与调用费用确认。保存后重启服务，再验收当前运行模型。支持OpenAI兼容Chat Completions响应格式；本机模型与云端模型二选一作为当前大模型推理后端。密钥只保存在本机配置，后台不回显。

## 分类服务

由模型提供方安装其权重与依赖，在本机开放分类HTTP接口。按“分类模型”页配置并启用。它与Ollama大模型是两条独立路径；字段对接见分类模型字段对接.md。分类建议不覆盖原规则，不自动封禁。

## 验收建议

换电脑先安装源码依赖，再检查协议监听和管理员登录；模型选择及连接验收独立进行。更换模型后，以保存的实际调用、引用及人工复核记录评价结果。
