# 分类模型字段对接

## 部署

AI组独立部署模型服务和权重。蜜迹接入本机HTTP/HTTPS端点 `/api/v1/detect` 或 `/detect`；地址示例 `http://127.0.0.1:8003/api/v1/detect`。服务的类别字典和模型版本由AI组提供，可承载正常与三类攻击等分类方案。

## 请求字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| path | string | 请求路径 |
| query | string | 查询参数 |
| body | string | 请求体摘要 |
| method | string | HTTP方法 |
| user_agent | string | 客户端标识 |
| source | string | 采集协议，当前请求分类为web |
| ip | string | 请求来源 |
| session_id | string | 采集会话编号 |

所有发送字段有长度上限，并对常见敏感键做基础脱敏。服务端不得将输入当作指令执行。

## 响应字段

```json
{"attack_type":"sqli","is_attack":true,"attack_prob":0.91,"ai_points":20,"high_risk":false,"reasons":["发现SQL组合特征"],"model_label":"model-version"}
```

attack_type为不超过60字符的类别；is_attack必须为布尔值；attack_prob范围0至1；ai_points范围0至25。high_risk、reasons、model_label为可选字段。普通分类不加有效分；建议融合分为规则分与有效加分之和，封顶100。

结果通过来源库、记录ID、时间、来源IP和会话身份共同关联原始证据。请求响应不等待分类；队列满和冷却跳过分别统计。单次超时0.1至5秒，连续三次故障进入30秒冷却；结果保留最多30天及10000条。

模型效果评估采用独立标注集，提供类别分布、逐类精确率、召回率、F1及混淆矩阵。接口验收验证数据传递与容错，模型评价验证识别效果，两者分开记录。
